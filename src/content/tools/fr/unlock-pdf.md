## Deux types de protection PDF

| Type | Ce que vous constatez | Ce que fait l’outil |
|---|---|---|
| Mot de passe d’ouverture (« utilisateur ») | Le PDF demande un mot de passe pour s’afficher | Le retire si vous saisissez le bon mot de passe |
| Restrictions (« propriétaire ») | Le PDF s’ouvre, mais l’impression, la copie ou la modification sont bloquées | Lève les restrictions, sans mot de passe à saisir |

## Pourquoi retirer un mot de passe ?

Beaucoup de documents arrivent protégés : relevés bancaires, bulletins de salaire envoyés par un logiciel de paie, factures de certains fournisseurs. C’est une bonne protection pendant l’envoi, mais elle devient gênante ensuite :

- La plupart des outils PDF, y compris [Fusionner PDF](/fr/fusionner-pdf) et [Compresser PDF](/fr/compresser-pdf), ne peuvent pas traiter un fichier verrouillé.
- Saisir le mot de passe à chaque ouverture est fastidieux pour un document que l’on consulte souvent.
- Certains portails en ligne refusent les PDF protégés lors du dépôt d’une pièce justificative.

## Problèmes fréquents

- **« Mot de passe incorrect »** : vérifiez les majuscules, les chiffres et la disposition du clavier. Pour les documents envoyés par une banque ou une caisse, le mot de passe est souvent indiqué dans l’e-mail ou le courrier qui accompagne le fichier (date de naissance, une partie d’un numéro de client…).
- **Le PDF s’ouvre sans mot de passe mais reste bloqué à l’impression** : laissez simplement le champ vide, il s’agit de restrictions et non d’un chiffrement à l’ouverture.
- **Vous ne connaissez pas le mot de passe** : aucun outil honnête ne peut l’ouvrir rapidement. Demandez le mot de passe ou une copie non protégée à l’expéditeur.

## Bonnes pratiques

Une fois déverrouillé, le PDF n’est plus protégé : rangez-le dans un dossier sûr. Si vous devez le renvoyer, vous pouvez le reprotéger avec votre propre mot de passe via [Protéger PDF](/fr/proteger-pdf). Et comme le traitement se fait entièrement sur votre appareil, votre mot de passe n’est jamais confié à un site tiers.

## Sur téléphone

Le déverrouillage fonctionne aussi depuis le navigateur d’un smartphone : choisissez le PDF dans l’app Fichiers ou vos pièces jointes enregistrées, saisissez le mot de passe et récupérez la copie sans protection dans vos téléchargements.
