## Le M4A, format audio d’Apple

Le **M4A** est un conteneur audio MPEG-4, généralement compressé en **AAC**. C’est le format utilisé par :

- l’app **Dictaphone** de l’iPhone (mémos vocaux) ;
- **iTunes** et **Apple Music** pour les morceaux importés ou achetés ;
- de nombreux **enregistreurs**, applications d’enregistrement d’appels et logiciels de visioconférence ;
- les **sonneries** iPhone (variante .m4r).

L’AAC est un excellent codec, souvent plus efficace que le MP3 à débit égal. Mais le **MP3** reste le format le plus universellement accepté : vieux autoradios, lecteurs MP3, certains logiciels de montage, plateformes de dépôt de fichiers ou formulaires en ligne.

## M4A et MP3 comparés

| | M4A (AAC) | MP3 |
|---|---|---|
| Efficacité de compression | Très bonne | Bonne |
| Compatibilité | Très bonne sur appareils récents | Universelle |
| Usage typique | iPhone, Apple Music, enregistreurs | Partage, lecteurs, autoradios |

## Choisir le débit

- **Mémo vocal, réunion, cours** : 128 kbps, le fichier reste léger et la voix parfaitement intelligible.
- **Musique** : 256 ou 320 kbps pour préserver la qualité d’origine.
- **Usage général** : 192 kbps, le réglage par défaut.

Comme l’on passe d’un format avec perte à un autre, inutile de viser un débit plus élevé que la source : un M4A à 128 kbps ne gagnera rien à être converti en MP3 à 320 kbps.

## Récupérer vos fichiers M4A

- **Mémos vocaux sur iPhone** : dans l’app Dictaphone, ouvrez l’enregistrement, touchez « … », puis Partager > Enregistrer dans Fichiers. Ouvrez ensuite cette page dans Safari et choisissez le fichier.
- **Sur Mac** : les mémos vocaux peuvent être glissés directement depuis l’app Dictaphone vers le bureau, puis déposés ici.
- **Bibliothèque iTunes ou Apple Music** : les morceaux importés se trouvent dans le dossier Musique de votre ordinateur. Seuls les fichiers sans DRM peuvent être convertis.
- **Enregistreurs et applis d’appel** : copiez le fichier sur votre ordinateur ou ouvrez-le depuis le gestionnaire de fichiers de votre téléphone.
