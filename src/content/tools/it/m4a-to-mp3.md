## Perché convertire M4A in MP3?

L’M4A con AAC è un ottimo formato, spesso di qualità leggermente superiore all’MP3 a parità di peso, e i dispositivi Apple lo usano ovunque. Ma l’MP3 resta il formato audio più universalmente accettato. Convertire è utile quando:

- **Un’autoradio, un vecchio lettore MP3 o uno smart speaker** non riconosce l’M4A.
- **Un sito, una piattaforma di podcast o un modulo di caricamento** accetta solo MP3.
- **Qualcuno su Windows o Android** non riesce ad aprire il memo vocale che gli hai inviato.
- **Un software di trascrizione o di editing** si aspetta un MP3.

## Scegliere la qualità

| Qualità audio | Peso al minuto | Ideale per |
|---|---|---|
| 128 kbps | ≈ 1 MB | Memo vocali, interviste, lezioni |
| 192 kbps | ≈ 1,4 MB | Ascolto quotidiano (predefinito) |
| 256 kbps | ≈ 1,9 MB | Musica iTunes (acquistata in AAC a 256 kbps) |
| 320 kbps | ≈ 2,4 MB | Qualità MP3 massima |

I memo vocali contengono parlato, quindi 128 kbps danno file piccoli e chiari. Per la musica, scegli un bitrate pari o superiore a quello della sorgente.

## Accetta anche AAC e audio MP4

I file **.aac** puri e i file **.mp4** solo audio vengono convertiti allo stesso modo. Per i video (con immagini) usa [MP4 in MP3](/it/mp4-in-mp3), che accetta tutti i formati video più diffusi.

## Problemi comuni

- **«Il file non può essere convertito.»** Potrebbe essere protetto da DRM (.m4p o download di Apple Music). Si possono convertire solo file non protetti.
- **L’MP3 pesa più dell’M4A.** L’AAC è più efficiente dell’MP3, quindi l’MP3 può richiedere un bitrate più alto per suonare allo stesso modo. Per il parlato, 128 kbps mantengono i file leggeri.

Più file insieme? Trascina un’intera cartella di memo vocali o un album: vengono convertiti uno dopo l’altro con la stessa qualità.

## Privacy dei memo vocali

Il tuo audio viene elaborato da FFmpeg compilato in WebAssembly, sul tuo dispositivo. Nulla viene caricato: un dettaglio rassicurante quando i memo vocali contengono conversazioni private.
