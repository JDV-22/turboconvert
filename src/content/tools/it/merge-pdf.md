## Unire PDF senza consegnarli a nessuno

La maggior parte dei siti per unire PDF carica i tuoi file sui propri server, li elabora lì e ti chiede di fidarti che vengano cancellati. TurboConvert funziona in modo diverso: il codice che unisce i file viene scaricato nel tuo browser e gira sul tuo dispositivo. Non viene caricato nulla, e puoi verificarlo negli strumenti per sviluppatori del browser, scheda *Rete*.

È quindi la scelta giusta per i documenti che preferiresti non condividere: contratti firmati, fatture, buste paga, documenti d’identità scansionati, domande di iscrizione o di partecipazione a un concorso.

## Cosa viene conservato quando unisci

TurboConvert copia ogni pagina, così com’è, in un nuovo PDF:

- **Il testo** resta selezionabile e ricercabile.
- **Immagini e scansioni** mantengono la risoluzione originale, senza ricompressione.
- **Formato e orientamento delle pagine** non cambiano: puoi mescolare pagine A4, Letter e orizzontali.
- **I link all’interno delle pagine** continuano a funzionare.

## Consigli per un risultato pulito

- **Dai ai file un nome in ordine** (per esempio `01-copertina.pdf`, `02-relazione.pdf`) prima di selezionarli: compariranno in quell’ordine e non dovrai riordinarli.
- **Mescoli scansioni e PDF digitali?** Prima unisci, poi usa [Comprimere PDF](/it/comprimere-pdf) una sola volta sul risultato per ottenere un file più leggero da inviare via email o PEC.
- **Ti servono i numeri di pagina su tutto il documento unito?** Aggiungili alla fine con [Numerare pagine PDF](/it/numerare-pagine-pdf).

## Problemi frequenti

**Un file viene rifiutato.** Se un PDF chiede una password all’apertura, va sbloccato prima di poterlo unire. Se invece è danneggiato, prova ad aprirlo nel visualizzatore PDF del browser e a stamparlo in un nuovo PDF, poi unisci la copia.

**L’ordine non è quello giusto.** I file vengono uniti nell’ordine dell’elenco: usa le frecce accanto a ogni file prima di fare clic su Converti. Se hai già scaricato il risultato, puoi correggere l’ordine delle pagine con Organizzare PDF.

**Il PDF finale è troppo pesante.** Unire non comprime: il file risultante pesa più o meno quanto la somma dei file di partenza. Una passata di compressione alla fine di solito basta.

**Da smartphone l’unione si blocca.** Con molti file grandi la memoria del telefono può non bastare. Unisci in due o tre gruppi più piccoli, oppure usa un computer per i fascicoli più voluminosi.
