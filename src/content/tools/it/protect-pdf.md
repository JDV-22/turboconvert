## Quando proteggere un PDF con password

Gli allegati email vengono inoltrati, i link al cloud vengono condivisi e i portatili si perdono. Una password fa sì che il documento resti illeggibile per chiunque non la conosca. Casi tipici:

- **Dichiarazioni dei redditi, buste paga ed estratti conto** inviati al commercialista o al proprietario di casa.
- **Referti medici e documenti del personale.**
- **Contratti e offerte** prima della firma.
- **Consegne ai clienti** inviate via email.

## Scegliere una password robusta

AES-256 non può essere forzato realisticamente per tentativi, ma una password debole può essere indovinata. Qualche regola:

- Usa **almeno 12 caratteri**, oppure una frase di quattro o più parole senza legame tra loro.
- Evita nomi, date di nascita e parole collegate al documento.
- **Non inviare mai la password nella stessa email** del PDF. Mandala via SMS, dilla al telefono o usa la funzione di condivisione di un gestore di password.

Per alleggerire il file prima di inviarlo, [comprimilo](/it/comprimere-pdf) prima di proteggerlo: un PDF cifrato va sbloccato di nuovo prima di poterlo modificare.

La password e il documento restano sul tuo dispositivo: TurboConvert non carica mai i file, quindi non esiste una copia su un server che possa finire in mani sbagliate.

## Cosa fa una password, e cosa no

- **Cifra il contenuto.** Senza password, testo e immagini del PDF non possono essere letti, nemmeno aprendo il file con un altro programma.
- **Non impedisce la condivisione.** Chiunque conosca la password può aprire il PDF, salvarlo, stamparlo o inoltrarlo insieme alla password.
- **Non nasconde il nome del file.** Dai al file un nome neutro (per esempio `documento-2026.pdf` invece di `stipendio-mario-rossi.pdf`) se il nome stesso è delicato.

## Problemi frequenti e soluzioni

**Chi riceve il file dice che la password non funziona.** Le password distinguono maiuscole e minuscole e gli spazi contano. Evita caratteri difficili da digitare sulla tastiera del telefono e invia la password come testo semplice, non in un messaggio formattato dove virgolette o trattini possono cambiare.

**Devo modificare un PDF protetto.** Sbloccalo con [Sbloccare PDF](/it/sbloccare-pdf) usando la sua password, fai le modifiche e poi proteggilo di nuovo.

**Un portale rifiuta il PDF.** Molti portali ufficiali non riescono a leggere i file cifrati. Carica sul portale la versione non protetta e riserva la protezione con password ai file che invii via email o condividi tramite link.
