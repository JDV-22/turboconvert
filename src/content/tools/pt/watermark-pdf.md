## Para que serve uma marca d’água

A marca d’água mostra a quem vê o documento qual é a situação dele e a quem ele se destina. Usos comuns:

- **CONFIDENCIAL / USO INTERNO** — atas, documentos de RH, relatórios financeiros.
- **RASCUNHO** — versões enviadas para revisão, para ninguém confundir com a versão final.
- **AMOSTRA / CÓPIA / CANCELADO** — documentos compartilhados só para consulta.
- **“Para [destinatário] – [data]”** — o RG, a CNH ou o holerite que você envia para uma imobiliária, uma loja ou um cadastro on-line. Escrever para quem e para que serve a cópia deixa um eventual vazamento muito menos útil para qualquer outra finalidade.

## Diagonal ou repetida?

| Disposição | Aparência | Indicada para |
|---|---|---|
| Diagonal, centralizada | Um texto grande atravessando a página | Carimbos de situação: RASCUNHO, CONFIDENCIAL |
| Repetida (mosaico) | Texto repetido pela página inteira | Documentos de identidade, fotos, prévias que você não quer que sejam reaproveitadas |

## Coloque marca d’água no seu documento antes de enviar

Imobiliárias, lojas e serviços on-line vivem pedindo cópia de RG, CNH, comprovante de residência ou holerite — e esses documentos são matéria-prima para golpes. Uma marca d’água repetida como *“Cadastro aluguel – Imobiliária X – out/2026”* sobre a página inteira mantém o documento legível para o que foi pedido, mas torna uma cópia roubada bem menos útil para qualquer outra coisa. Use uma opacidade moderada (20–30%) para que a foto e os números continuem legíveis.

## Dicas

- **Seja breve.** Uma a três palavras ficam melhores na diagonal; frases mais longas funcionam melhor repetidas.
- **Marque as cópias, não os originais.** Guarde uma versão limpa para você e envie a versão com marca d’água.
- **Numere também** com [Numerar páginas](/pt/numerar-paginas-pdf) em documentos formais.
- **Feche com senha.** Em arquivos sensíveis, aplique primeiro a marca d’água e depois [proteja o PDF com senha](/pt/proteger-pdf).

Como a marca d’água é aplicada no seu navegador, documentos como passaportes, contratos ou trabalhos ainda não divulgados nunca são enviados a um servidor de terceiros.

## Problemas comuns e soluções

**A marca d’água esconde o texto.** Baixe a opacidade para 15–20%. Texto preto continua legível sob uma marca d’água clara.

**A marca d’água quase não aparece.** Aumente a opacidade ou use a disposição repetida, para o texto cobrir mais da página.

**Meu texto longo fica cortado ou pequeno.** Uma única linha diagonal tem espaço limitado. Encurte o texto ou mude para repetida, que espalha uma frase mais curta pela página.

**Preciso de um logotipo em vez de texto.** Marcas d’água com imagem não são aceitas. Uma marca de texto com o nome da empresa costuma bastar para indicar a autoria.

**Quero remover a marca d’água.** Se você a adicionou aqui, basta usar o seu arquivo original, sem marca — ele nunca foi modificado.
