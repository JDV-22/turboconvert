## Por que é difícil editar PDF — e o que o conversor faz

O PDF foi feito para ter a mesma aparência em qualquer lugar, não para ser editado. Dentro do arquivo não existem parágrafos nem títulos, só pedaços de texto posicionados em pontos exatos da página. Para entregar um documento do Word utilizável, o conversor faz o caminho inverso: agrupa os trechos em linhas e as linhas em parágrafos, identifica títulos pelo tamanho e peso da fonte, mantém **negrito** e *itálico* e recoloca as imagens no lugar.

O resultado é um `.docx` de verdade, com texto corrido — e não uma foto de cada página colada no Word —, então você corrige um erro de digitação, reescreve uma cláusula ou atualiza uma data e o resto do parágrafo se ajusta normalmente.

## O que converte bem e o que precisa de revisão

| Seu PDF | Resultado no Word |
|---|---|
| Cartas, contratos, relatórios e currículos exportados do Word ou do Google Docs | Parágrafos e títulos limpos, prontos para editar |
| Documentos com fotos, logotipos ou gráficos | Imagens mantidas e posicionadas perto do lugar original |
| Tabelas simples (orçamentos, listas de preços) | Reconstruídas como tabelas, da melhor forma possível — confira a largura das colunas |
| Layouts com várias colunas, folhetos, revistas | O texto está todo lá, mas o layout pode precisar de ajustes |
| Páginas digitalizadas ou fotos de papel | Nenhum texto editável — use antes o [OCR de PDF](/pt/ocr-pdf) |
| PDFs com cara de planilha (extratos, relatórios cheios de números) | Melhor como planilha, com o [PDF para Excel](/pt/pdf-para-excel) |

**Como saber se o seu PDF é digitalizado:** abra o arquivo e tente selecionar uma palavra. Se der para destacar palavras individuais, é um PDF digital e vai converter bem. Se só der para desenhar uma caixa em volta da página inteira, é uma imagem.

## Dicas para um DOCX bem limpo

- **Comece pela melhor fonte.** Se você tem o arquivo original que gerou o PDF, edite esse. Se não, use o PDF exportado digitalmente, e não uma digitalização ou uma cópia “impressa em PDF” de uma digitalização.
- **Só precisa das palavras?** Para copiar o texto para um e-mail, um site ou um tradutor, o [PDF para texto](/pt/pdf-para-texto) entrega texto simples sem layout para arrumar.
- **Confira tabelas e listas depois de converter.** São as partes que mais podem precisar de um ajuste rápido — mudar a largura de uma coluna ou reaplicar um marcador leva segundos.
- **Converta de volta quando terminar.** Depois de editar, transforme o documento de novo em PDF com o [Word para PDF](/pt/word-para-pdf), para que ele fique igual para todo mundo que receber.

## Problemas comuns e soluções

**O documento veio em branco ou só com imagens.** O PDF é uma digitalização. Passe pelo OCR para recuperar o texto.

**“Este PDF está protegido por senha.”** Um PDF que pede senha para abrir precisa ser desbloqueado antes da conversão. Se você sabe a senha, o Desbloquear PDF a remove em um passo.

**As linhas quebram em lugares estranhos.** Alguns PDFs são gerados linha por linha, e não parágrafo por parágrafo. Ativar as marcas de formatação do Word (¶) facilita encontrar e apagar as quebras sobrando.

**O texto aparece fora de ordem numa página com colunas.** A ordem de leitura de um PDF nem sempre é a ordem visual. Mova os parágrafos para o lugar certo, ou converta só as páginas afetadas e ajuste separadamente.
