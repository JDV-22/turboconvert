## Por que transformar um PDF em slides?

É comum receber apresentações em PDF — palestras, propostas de clientes, material de curso. Voltar para o PowerPoint ajuda quando você precisa:

- **Apresentar** com o modo de apresentador do PowerPoint, um passador de slides e tela cheia.
- **Reaproveitar alguns slides** na sua própria apresentação.
- **Atualizar um número ou uma data** num slide cujo arquivo original você não tem mais.
- **Transformar um documento em apresentação** — uma página de relatório por slide para conduzir uma reunião.

## O que esperar

| Conteúdo do PDF | No PowerPoint |
|---|---|
| Apresentações exportadas para PDF | Um slide por página, com a aparência do original |
| Blocos de texto simples | Editáveis onde o texto pode ser extraído |
| Gráficos, diagramas, fotos | Mantidos visualmente como parte do slide |
| Animações, transições, anotações | Não existem no PDF, então não podem ser recuperadas |
| Páginas digitalizadas | Só imagens nos slides, sem texto editável |

## Dicas

- **Fique só com os slides de que precisa.** Separe-os antes com o [Dividir PDF](/pt/dividir-pdf) ou reordene e exclua páginas com o [Organizar PDF](/pt/organizar-pdf).
- **Precisa de um slide como imagem** para um site ou uma postagem? O [PDF para JPG](/pt/pdf-para-jpg) é mais simples.
- **É quase tudo texto?** Para um documento que você quer reescrever, o [PDF para Word](/pt/pdf-para-word) entrega parágrafos corridos em vez de slides.
- **Terminou de editar?** Transforme a apresentação de volta em um arquivo fácil de compartilhar com o [PPT para PDF](/pt/ppt-para-pdf).

Como a conversão acontece no seu navegador, propostas ainda não apresentadas e treinamentos internos continuam privados.

## Problemas comuns e soluções

**Não consigo editar parte do texto.** Texto que faz parte de uma imagem no PDF — uma captura de tela, um logotipo, um slide digitalizado — continua sendo parte dessa imagem. Redigite-o numa nova caixa de texto no slide.

**Os slides têm um tamanho incomum.** Os slides seguem as proporções das páginas do PDF. Uma apresentação exportada para PDF mantém o formato 16:9 ou 4:3; um documento A4 gera slides na vertical. Mude o tamanho do slide no menu *Design* do PowerPoint, se precisar.

**O arquivo ficou pesado.** Cada slide inclui uma imagem da página, então documentos longos com muitas imagens geram apresentações pesadas. Converta só as páginas necessárias.

**As fontes mudam quando eu edito.** As fontes usadas no PDF podem não estar instaladas no seu computador, então o PowerPoint mostra uma substituta quando você edita o texto.
