## PDFs zusammenfügen, ohne sie aus der Hand zu geben

Die meisten Online-Tools zum PDF-Zusammenfügen laden Ihre Dateien auf ihre Server hoch, verarbeiten sie dort und bitten Sie, darauf zu vertrauen, dass sie anschließend gelöscht werden. TurboConvert arbeitet anders: Der Code zum Zusammenfügen wird in Ihren Browser geladen und läuft auf Ihrem eigenen Gerät. Nichts wird hochgeladen – das können Sie selbst in den Entwicklertools Ihres Browsers im Tab *Netzwerk* überprüfen.

Damit eignet sich das Tool gerade für Unterlagen, die Sie ungern weitergeben: unterschriebene Verträge, Rechnungen, Gehaltsabrechnungen, eingescannte Ausweise oder Bewerbungsunterlagen. Typischer Fall: Anschreiben, Lebenslauf und Zeugnisse sollen als **eine einzige PDF-Bewerbung** verschickt werden.

## Was beim Zusammenfügen erhalten bleibt

TurboConvert kopiert jede Seite unverändert in ein neues PDF:

- **Text** bleibt markierbar und durchsuchbar.
- **Bilder und Scans** behalten ihre ursprüngliche Auflösung – keine erneute Komprimierung.
- **Seitenformate und Ausrichtung** bleiben bestehen; Sie können also A4-, Letter- und Querformatseiten mischen.
- **Links innerhalb der Seiten** funktionieren weiterhin.

## Tipps für ein sauberes Ergebnis

- **Benennen Sie die Dateien vorher in der richtigen Reihenfolge** (zum Beispiel `01-anschreiben.pdf`, `02-lebenslauf.pdf`). Wählen Sie sie dann gemeinsam aus, sparen Sie sich das Umsortieren.
- **Scans und digitale PDFs gemischt?** Fügen Sie zuerst alles zusammen und nutzen Sie dann einmal [PDF verkleinern](/de/pdf-verkleinern) für das Ergebnis – so wird die Datei leicht genug für den E-Mail-Versand.
- **Durchgehende Seitenzahlen gewünscht?** Fügen Sie sie anschließend mit [Seitenzahlen einfügen](/de/pdf-seitenzahlen-einfuegen) hinzu.
- **Fotos oder JPG-Scans dabei?** Wandeln Sie die Bilder zuerst mit [JPG in PDF](/de/jpg-in-pdf) um und fügen Sie das Ergebnis dann mit Ihren übrigen Dokumenten zusammen.

## Häufige Probleme und Lösungen

**„Dieses PDF ist passwortgeschützt.“** Verschlüsselte PDFs lassen sich ohne Passwort nicht neu schreiben. Entsperren Sie die Datei zuerst, fügen Sie sie dann zusammen und schützen Sie das Ergebnis bei Bedarf erneut.

**Die Reihenfolge stimmt nicht.** Entscheidend ist die Liste über dem Button Umwandeln: Die oberste Datei kommt zuerst. Verschieben Sie Dateien mit den Pfeilen und wandeln Sie erneut um – das dauert nur Sekunden.

**Die fertige Datei ist zu groß.** Beim Zusammenfügen wird nichts komprimiert, die Größe ist ungefähr die Summe der Einzeldateien. Bei Scans hilft anschließendes Verkleinern meist deutlich.

**Das Inhaltsverzeichnis in der Seitenleiste fehlt.** Lesezeichen der Originale werden nicht übernommen. Die Seiten selbst, einschließlich anklickbarer Links, sind vollständig vorhanden.
