## Why number a PDF?

Page numbers make a document easy to discuss and hard to misplace: "see page 14" works in a meeting, a printed stack can be put back in order, and a reviewer can confirm nothing is missing. They are expected — or required — for:

- **Contracts and legal documents**, especially with the "1 of N" format.
- **Theses, reports and course work**, where submission rules often specify numbering.
- **Merged documents**, such as a proposal assembled from several PDFs.
- **Print jobs and manuals**, so loose pages can be put back in order.

## Choosing position and format

| Option | Recommended for |
|---|---|
| Bottom center, "1, 2, 3" | Books, reports, academic work — the classic choice |
| Bottom right, "1 of 10" | Contracts, forms and anything printed and signed |
| Top right | Documents with a footer already in use, or legal pleadings |

## Tips

- **Number last.** Merge, reorder and delete pages first with [Organize PDF](/organize-pdf); add numbers once the final order is set.
- **Combining several files?** [Merge PDF](/merge-pdf) them, then number the merged document so numbering is continuous.
- **Marking drafts?** Combine page numbers with a "DRAFT" or "CONFIDENTIAL" stamp using [Watermark PDF](/watermark-pdf).

Numbers are added inside your browser — the document is never sent anywhere, which matters for contracts and unpublished work.

## Common problems and fixes

**The number overlaps a footer or a logo.** Many templates already use the bottom of the page. Switch the position to Top right, or Bottom right if the footer text is centred.

**The numbering should continue from another file.** Set *Start at* to the next number — if part 1 ended on page 48, start part 2 at 49. Better still, merge the parts and number the combined file once.

**I need roman numerals or a prefix like "Page 3".** The tool writes Arabic numerals in the two formats shown — "3" or "3 of 10". For a front section in roman numerals, keep those pages separate and number only the main part.

**Some pages are sideways.** Fix their orientation first with [Rotate PDF](/rotate-pdf) so the numbers end up where readers expect them.

**"This PDF is password-protected."** Unlock it first. If it must stay protected, number the unlocked copy and protect it again afterwards.

## Numbering for print

For double-sided printing, bottom center is the safest choice: it stays in the same place whether the page is on the left or the right. Leave a little margin at the bottom of your document so the number doesn't collide with the last line of text.
