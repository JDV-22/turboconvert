## What PNG to PDF is good for

PNG is the format of screenshots and graphics. Wrapping them in a PDF makes them easier to share, print and file:

- **Bug reports and tutorials** — a series of screenshots in order, as one document.
- **Design proofs** — mock-ups and graphics sent to a client for approval.
- **Scanned pages saved as PNG** — turn them back into a proper multi-page document.
- **Online forms** — submit several images as a single PDF where only one file is allowed.

## Page size and margins

| Option | Result |
|---|---|
| Same as image | Page matches each image exactly — no white borders |
| A4 / Letter | Standard page; the image is scaled to fit without distortion |
| Margin None / Small / Large | Space between the image and the page edge |

For a set of screenshots of different sizes, *Same as image* avoids huge white borders; for printing, A4 or Letter with a small margin gives a tidy result.

## Tips

- **Name files in order** (`step-01.png`, `step-02.png`…) so they arrive in the right sequence.
- **Large PDF?** Full-resolution PNG screenshots can add up. [Compress PDF](/compress-pdf) reduces the size before you share it.

## Common problems and fixes

**Pages have very different sizes.** With *Same as image*, a tall phone screenshot and a wide desktop screenshot produce pages of different shapes. Choose A4 or Letter if you want a uniform document.

**The PDF is surprisingly heavy.** PNG is lossless, and large screenshots or graphics stay large inside the PDF. Compress the PDF afterwards, or convert the images to JPG first if they are photos.

**The order is wrong.** Images are added in the order you select them. Use the up and down arrows next to each file to fix it before converting.

**A screenshot contains text I need to copy.** The PDF shows the screenshot as a picture. Run the PDF or the image through OCR to get the text.

**HEIC photos are rejected here.** iPhone photos are accepted on the JPG to PDF page, which uses the same options.

## Private by default

Screenshots often contain more than intended — email addresses, account numbers, chat messages. Because the PDF is built inside your browser, none of it is ever uploaded.
