## Lo mejor de los dos mundos: transparencia y ligereza

El **PNG** es el formato clásico de las imágenes con transparencia: logotipos, iconos, diseños recortados, capturas de pantalla. Pero como no tiene pérdida, pesa mucho, sobre todo cuando se usa para fotos o imágenes grandes.

El **WebP** también admite transparencia y comprime con mucha más eficiencia. Es el formato recomendado para mostrar este tipo de imágenes en una web: páginas más rápidas, mejor puntuación en PageSpeed y menos ancho de banda consumido.

| | PNG | WebP |
|---|---|---|
| Transparencia | Sí | Sí |
| Compresión | Sin pérdida | Con pérdida (ajustable) |
| Peso | Pesado | Ligero |
| Compatibilidad | Universal | Todos los navegadores actuales |
| Ideal para | Edición, archivo, impresión | Publicación en la web |

## ¿Cuándo convertir tus PNG a WebP?

- **Web o tienda online**: fotos de producto recortadas, banners, ilustraciones.
- **Capturas de pantalla en un artículo**: suelen guardarse en PNG por defecto y se aligeran mucho en WebP.
- **Temas y aplicaciones web**: iconos y elementos de la interfaz.

En cambio, conserva tus PNG originales para editar e imprimir: el WebP es un formato de publicación.

## Usar tus WebP en una web

- **WordPress** acepta subir imágenes WebP a la biblioteca de medios desde la versión 5.8.
- **Shopify, Wix, Squarespace** y la mayoría de los creadores de webs también los admiten.
- **En HTML**, basta con `<img src="imagen.webp" alt="…">`: todos los navegadores actuales lo muestran.

Recuerda rellenar el texto alternativo (atributo alt) e indicar las dimensiones de la imagen: es bueno para la accesibilidad y para el SEO.

## Ajustar la calidad

Al **82 %** (por defecto), el resultado es excelente para la mayoría de las imágenes. Si la imagen tiene texto fino o bordes muy nítidos, sube hacia el **90 %** para evitar ligeros desenfoques alrededor de las letras. Para miniaturas, un 70 % suele bastar.

Para tus fotos en JPG, usa [JPG a WebP](/es/jpg-a-webp). Para aligerar una imagen sin cambiar de formato, prueba [Comprimir imagen](/es/comprimir-imagen). Y si necesitas volver al PNG, [WebP a PNG](/es/webp-a-png) hace el camino inverso.

Tus imágenes se convierten en local, en tu navegador: no se sube nada, ni siquiera los diseños o maquetas que todavía no se han publicado.
