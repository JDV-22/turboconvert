## ¿Por qué pasar tus JPG a WebP?

El **WebP**, desarrollado por Google, comprime las imágenes con más eficiencia que el JPG. Con una calidad visual comparable, un archivo WebP suele pesar **entre un 25 y un 35 % menos**. En una página que muestra una decena de fotos, la diferencia se nota directamente en el tiempo de carga.

Imágenes más ligeras significan:

- **una web más rápida**, sobre todo en el teléfono y con datos móviles;
- **mejores indicadores de rendimiento** (las Core Web Vitals de Google, entre ellas el LCP, son sensibles al peso de las imágenes);
- **menos almacenamiento y ancho de banda** en tu alojamiento.

Las herramientas de auditoría como PageSpeed Insights recomiendan a menudo «publicar imágenes en formatos modernos», con el WebP a la cabeza.

## ¿JPG o WebP?

| | JPG | WebP |
|---|---|---|
| Peso con la misma calidad | Referencia | Normalmente un 25–35 % menos |
| Transparencia | No | Sí |
| Compatibilidad con navegadores | Universal | Todos los navegadores actuales |
| Compatibilidad con programas | Universal | Buena, pero no total |
| Ideal para | Compartir, imprimir, archivar | Webs, tiendas online, blogs |

Para enviar una foto por correo o imprimirla, quédate con el JPG. Para mostrarla en una web, el WebP es la mejor opción.

## Ajustar bien la calidad

La calidad por defecto (**82 %**) da resultados excelentes en la mayoría de las fotos. Algunas referencias:

- **85–90 %**: fotos de producto a gran tamaño, portafolios;
- **75–82 %**: imágenes de artículos, galerías;
- **60–70 %**: miniaturas.

Para imágenes en PNG (logotipos, diseños con transparencia), usa [PNG a WebP](/es/png-a-webp), que conserva la transparencia. Y para volver al JPG, [WebP a JPG](/es/webp-a-jpg) hace el camino inverso.

## El método completo para optimizar imágenes web

1. Redimensiona primero al tamaño real de visualización (por ejemplo, 1200 px de ancho).
2. Convierte a WebP con una calidad de alrededor del 80 %.
3. Guarda tus JPG originales a resolución completa como copia.

Si solo quieres aligerar una imagen sin cambiar de formato, prueba [Comprimir imagen](/es/comprimir-imagen).

## Subir tus WebP a la web

WordPress acepta imágenes WebP en la biblioteca de medios desde la versión 5.8, y la mayoría de los creadores de webs y plataformas de comercio electrónico también las admiten. En HTML basta con una etiqueta `<img src="foto.webp" alt="…">`. No olvides el texto alternativo: ayuda tanto a la accesibilidad como al posicionamiento.

Todo se hace en tu navegador, sin subir tus fotos: práctico para preparar las imágenes de la web de un cliente que todavía es confidencial.
