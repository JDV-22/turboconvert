## WebP: el formato de la web… pero no del resto

Creado por Google, el **WebP** lo usa hoy una gran parte de los sitios web: con la misma calidad pesa menos que el JPG (a menudo entre un 25 y un 35 % menos) y puede tener transparencia, como el PNG. Por eso, cuando guardas una imagen de una web, una red social o una tienda online, muchas veces obtienes un archivo **.webp**.

El problema llega después, fuera del navegador:

- un **programa de edición** o una **suite ofimática** antigua no lo abre;
- un **formulario en línea** solo acepta JPG o PNG;
- una **impresora fotográfica** o un servicio de revelado no reconoce el formato;
- un **amigo** no consigue verlo en un dispositivo antiguo.

La solución: convertirlo a **JPG**, el formato de imagen más universal que existe.

## WebP, JPG o PNG: ¿cuál elegir?

| | WebP | JPG | PNG |
|---|---|---|---|
| Compresión | Con o sin pérdida | Con pérdida | Sin pérdida |
| Transparencia | Sí | No | Sí |
| Peso | El más ligero | Medio | Pesado |
| Compatibilidad | Navegadores, programas recientes | Universal | Universal |
| Ideal para | Sitios web | Fotos, compartir, imprimir | Logotipos, transparencia |

Para una **foto**, elige JPG. Para un **logotipo, un icono o una imagen recortada** con fondo transparente, mejor [WebP a PNG](/es/webp-a-png).

## ¿Qué calidad elegir?

El valor por defecto (**92 %**) sirve para casi todo: es imposible distinguir el JPG del WebP original. Baja al **80–85 %** si el archivo debe ser ligero (correo, formulario) y evita bajar del 70 %: como el WebP ya se comprimió una vez, una segunda compresión demasiado fuerte hace aparecer defectos enseguida.

## Convertir por lotes

¿Tienes decenas de imágenes descargadas de una web o de un banco de imágenes? Arrástralas todas de una vez: se convierten seguidas y se agrupan en un ZIP. Las dimensiones en píxeles se mantienen idénticas; para reducirlas, usa después [Redimensionar imagen](/es/redimensionar-imagen).

## Problemas frecuentes

- **El archivo se llama .jpg pero no se abre**: algunas webs entregan WebP con una extensión engañosa. Cámbiale el nombre a .webp y conviértelo aquí.
- **El fondo se ha vuelto blanco**: la imagen original era transparente; usa la conversión a PNG.
- **¿Quieres hacer lo contrario?** Para aligerar fotos destinadas a una web, usa [JPG a WebP](/es/jpg-a-webp).

No se sube ninguna imagen: la conversión se hace por completo en tu navegador.
