Contrairement à Windows, macOS sait fusionner des PDF sans rien installer, et même de plusieurs façons. Le hic : ces méthodes sont un peu cachées et chacune a ses manies. Le glisser-déposer d’Aperçu est capricieux, le Finder décide de l’ordre à votre place, et il est facile d’écraser l’original. Voici les quatre méthodes qui marchent, quand utiliser chacune, et comment régler les problèmes courants.

## Comparatif rapide

| Méthode | Idéale pour | Attention à |
|---|---|---|
| Action rapide du Finder | Combiner des fichiers entiers en quelques secondes | L’ordre suit le tri du Finder |
| Barre latérale d’Aperçu | Insérer des pages à un endroit précis | Glisser-déposer délicat, risque d’écraser l’original |
| App Raccourcis | Répéter souvent la même fusion | Réglage initial |
| Outil dans le navigateur | Beaucoup de fichiers, ordre clair, n’importe quel Mac | Un navigateur récent |

## Méthode 1 : l’action rapide du Finder (la plus rapide)

Depuis macOS Mojave, le Finder peut créer un PDF à partir de plusieurs fichiers en un clic :

1. Rassemblez les PDF dans un même dossier. **Renommez-les avec un préfixe numérique** — `01-couverture.pdf`, `02-contrat.pdf`, `03-annexe.pdf` — pour qu’ils se trient dans le bon ordre.
2. Triez la fenêtre par nom et sélectionnez les fichiers (Cmd-clic pour en choisir plusieurs).
3. Faites un clic droit (ou Ctrl-clic) sur la sélection et choisissez **Actions rapides > Créer un PDF**.

Un nouveau PDF apparaît dans le dossier, nommé d’après le premier fichier. La même action fonctionne avec des images : sélectionnez des JPG ou des photos HEIC et vous obtenez un PDF de plusieurs pages.

**Limites :** impossible de réordonner dans l’action, et aucune option de format de page. Vérifiez le résultat et corrigez l’ordre dans Aperçu si besoin.

## Méthode 2 : Aperçu (précis mais capricieux)

Aperçu est l’outil cité par la plupart des tutoriels. Il est efficace une fois le geste maîtrisé :

1. **Faites d’abord une copie** : ouvrez le premier PDF puis **Fichier > Dupliquer**, ou prévoyez d’utiliser *Exporter* à la fin. Aperçu enregistre les modifications dans le fichier ouvert.
2. Choisissez **Présentation > Vignettes** pour afficher les vignettes des pages dans la barre latérale.
3. Glissez le deuxième PDF depuis le Finder dans la barre latérale, **entre deux vignettes** ou sous la dernière. Un trait indique où les pages vont s’insérer. Autre possibilité : sélectionnez une vignette puis **Édition > Insérer > Page à partir d’un fichier**.
4. Glissez les vignettes pour réordonner les pages ; appuyez sur Supprimer pour retirer une page.
5. Choisissez **Fichier > Exporter au format PDF** et donnez un nouveau nom au fichier fusionné.

**Les limites d’Aperçu :**

- Déposer un fichier sur la page principale au lieu de la barre latérale l’ouvre à part au lieu de le fusionner.
- Avec beaucoup de fichiers, il faut les glisser un par un et faire défiler une longue liste de vignettes.
- Si vous fermez simplement la fenêtre, Aperçu conserve les modifications dans votre fichier d’origine.
- Les PDF protégés par mot de passe doivent être déverrouillés avant d’insérer leurs pages.

## Méthode 3 : Raccourcis (pour les fusions répétitives)

Si vous fusionnez chaque mois le même type de documents — factures, relevés d’heures —, créez un raccourci une fois pour toutes :

1. Ouvrez l’app **Raccourcis** et créez un nouveau raccourci.
2. Dans ses détails, activez **Utiliser comme action rapide** et **Finder**, en acceptant les PDF en entrée.
3. Ajoutez l’action **Créer un PDF** (elle combine les fichiers reçus), puis **Enregistrer le fichier** pour choisir la destination.

Désormais, sélectionnez les fichiers dans le Finder, faites un clic droit et lancez votre raccourci depuis les actions rapides. Raccourcis existe aussi sur iPhone et iPad : la logique est la même.

## Méthode 4 : un outil dans le navigateur (ordre clair, autant de fichiers que voulu)

Avec beaucoup de fichiers, ou pour voir clairement l’ordre, un outil web est plus simple. La plupart des sites de fusion envoient vos documents sur leurs serveurs ; [Fusionner PDF](/fr/fusionner-pdf) de TurboConvert, non : la fusion se fait dans Safari, Chrome ou Firefox, sur votre Mac.

1. Ouvrez [Fusionner PDF](/fr/fusionner-pdf) et cliquez sur **Choisir des fichiers**, ou glissez les PDF depuis le Finder sur la page.
2. Utilisez les flèches pour mettre les fichiers dans le bon ordre.
3. Cliquez sur **Convertir** : le PDF fusionné arrive dans votre dossier Téléchargements.

Les pages sont copiées telles quelles : le texte reste sélectionnable, les images ne sont pas recompressées, les formats de page différents sont conservés. Les signets (sommaire) des fichiers d’origine ne sont pas repris. Chaque fichier peut peser jusqu’à 200 Mo.

## Fusionner sur iPhone et iPad

L’app **Fichiers** offre la même fonction que le Finder :

1. Ouvrez Fichiers et allez dans le dossier contenant les PDF (enregistrez d’abord les pièces jointes dans Fichiers si besoin).
2. Touchez **Sélectionner**, puis les PDF dans l’ordre voulu.
3. Touchez le bouton **Plus** (trois points) et choisissez **Créer un PDF**.

La méthode du navigateur fonctionne aussi sur iOS : ouvrez [Fusionner PDF](/fr/fusionner-pdf) dans Safari et choisissez les fichiers depuis l’app Fichiers.

## Résoudre les problèmes courants

**Le PDF fusionné est énorme.** La fusion n’ajoute pas de poids, mais les scans s’additionnent vite. Passez le résultat une fois dans [Compresser PDF](/fr/compresser-pdf) ; notre guide pour [réduire un PDF avant de l’envoyer par mail](/fr/blog/reduire-taille-pdf-pour-mail) donne les limites de Gmail, Outlook et iCloud.

**Un fichier refuse d’être fusionné.** Il est probablement chiffré. Si vous connaissez le mot de passe, retirez-le avec [Déverrouiller PDF](/fr/deverrouiller-pdf) (ou ouvrez-le dans Aperçu, saisissez le mot de passe et exportez une copie), puis fusionnez.

**Des pages sont de travers.** Faites-les pivoter dans Aperçu (sélectionnez la vignette, Cmd+R) ou avec [Pivoter PDF](/fr/pivoter-pdf) avant la fusion.

**Vous n’avez besoin que de certaines pages.** Extrayez-les d’abord avec [Diviser PDF](/fr/diviser-pdf), ou supprimez les pages inutiles après coup avec [Organiser PDF](/fr/organiser-pdf).

**Les formulaires ne fonctionnent plus après la fusion.** Des champs de formulaire peuvent entrer en conflit quand deux PDF utilisent les mêmes noms de champs. Remplissez et aplatissez les formulaires (dans Aperçu : *Fichier > Imprimer > Enregistrer au format PDF*) avant de fusionner.

**Vous voulez une numérotation continue.** Ajoutez-la à la fin avec [Numéroter PDF](/fr/numeroter-pdf), pour qu’elle suive l’ordre final.

## Avant d’envoyer le fichier fusionné

Quelques vérifications évitent des allers-retours embarrassants :

- **Faites défiler toutes les pages** en vignettes : une page manquante ou en double saute aux yeux.
- **Contrôlez le poids** dans le Finder (*Lire les informations*). Au-delà de 20-25 Mo, beaucoup de messageries refusent le fichier.
- **Donnez-lui un nom explicite**, par exemple `Dossier-candidature-Martin-2026.pdf`, plutôt que le nom du premier fichier.
- **Protégez-le s’il est sensible** : notre guide pour [mettre un mot de passe sur un PDF](/fr/blog/mettre-un-mot-de-passe-sur-un-pdf) montre comment faire dans Aperçu.

## Quelle méthode choisir ?

- **Deux ou trois fichiers entiers :** l’action rapide du Finder.
- **Insérer une page au milieu d’un document :** Aperçu.
- **La même fusion chaque semaine :** un raccourci.
- **Dix fichiers ou plus, ou pour voir et changer l’ordre facilement :** [Fusionner PDF](/fr/fusionner-pdf) dans votre navigateur.

Ces quatre méthodes gardent vos fichiers sur votre Mac : aucune n’envoie quoi que ce soit en ligne.
